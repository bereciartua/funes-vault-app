OpenAI Responses API
credential: remote token
agentKind: openai_responses
symbol: curlybraces
needsLiteralSecret: true

snippet (shellCommand):
curl "https://api.openai.com/v1/responses" \
  -H "content-type: application/json" \
  -H "authorization: Bearer $OPENAI_API_KEY" \
  -d '{"model":"gpt-6-astra","input":"What do my memories say about how I like to work?","tools":[{"type":"mcp","server_label":"funes","server_url":"https://my-mac.tail1234.ts.net/r/q7Zk2vN4bXwP9sL1mT6hYa/mcp","authorization":"'"$FUNES_REMOTE_TOKEN"'","allowed_tools":["list_memory_categories","request_memory","get_memory_request","open_in_funes"],"require_approval":"never"}]}'

steps:
1. In Terminal, set FUNES_REMOTE_TOKEN to the remote token (Copy Remote Token… below) and OPENAI_API_KEY to your API key, then run the command.
2. This example allows only the read tools, without approval in the API. To let it suggest memories too, remove allowed_tools and handle approval requests in your code.

warnings:
- The API calls tools without asking you, so this agent's access in Funes Vault is the only limit. Give it only the categories it needs.
- Cloud agents often run while you're away. With Ask before sharing on, a request waits up to 45 s for you at this Mac; after that, you can still approve it from the pending list within 15 minutes.

footnote: The authorization field takes the bare token, without Bearer.
